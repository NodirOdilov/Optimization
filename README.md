# Методы оптимизации

Репозиторий содержит решения задач, лабораторные работы, отчёты и вспомогательные материалы по курсу **«Методы оптимизации»**.

Материалы организованы по темам и отдельным заданиям. В каждой директории хранятся соответствующие математические постановки, пояснения, программные реализации, вычисления и результаты.

---

## Содержание репозитория

В репозитории могут находиться:

- задачи линейного программирования;
- двойственные задачи;
- численные методы оптимизации;
- лабораторные работы;
- практические задания;
- математические выводы;
- реализации на Python;
- Jupyter Notebook;
- отчёты в формате PDF;
- проверки и анализ полученных результатов.

### Jupyter Notebook

Файлы `.ipynb` могут содержать:

- постановку задачи;
- математические формулы;
- пояснения;
- реализацию на Python;
- вычисления;
- численные результаты;
- проверку полученных решений;
- выводы.

### PDF-отчёты

PDF-файлы являются экспортированными версиями выполненных работ и предназначены для удобного просмотра и сдачи.

## Установка

Клонирование репозитория:

```bash
git clone https://github.com/NodirOdilov/Optimization.git
```

Переход в директорию проекта:

```bash
cd Optimization
```

Установка необходимых зависимостей:

```bash
python -m pip install -r requirements.txt
```

---

## Запуск Jupyter Notebook

Ноутбуки можно открывать с помощью:

- Visual Studio Code с расширением Jupyter;
- Jupyter Notebook;
- JupyterLab.

Для запуска Jupyter Notebook из терминала:

```bash
jupyter notebook
```

Для запуска JupyterLab:

```bash
jupyter lab
```

При работе в Visual Studio Code необходимо выбрать соответствующее Python-ядро и выполнить ячейки последовательно либо использовать команду **Run All**.

## Общий порядок выполнения заданий

Для каждого задания используется следующий подход:

1. Анализ математической задачи.
2. Формализация оптимизационной модели.
3. Вывод необходимых формул и преобразований.
4. Реализация решения на Python, если это требуется.
5. Выполнение вычислений.
6. Проверка полученного решения.
7. Интерпретация результатов.
8. Подготовка итогового отчёта.
